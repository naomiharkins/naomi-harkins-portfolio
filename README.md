The portfolio includes only completed work supported by the source documents. Its current focus is data quality, visual usability, research, analytics, and cross-platform information review. Direct assistive-technology testing is not presented as prior experience.

## Open locally

The site has no build step.

1. Keep the folder structure intact.
2. Open `index.html` in a browser.
3. For the most accurate local behavior, run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Publish

See [`PUBLISH_TO_GITHUB.md`](PUBLISH_TO_GITHUB.md) for browser and command-line instructions. Upload the **contents of this folder**, not the ZIP file, and make sure `index.html` is at the repository root.

## Privacy

The public case studies use sanitized summaries. They do not include the original audit's unnecessary contact details or the full packaged course datasets.
