# Scientific Chart Readability Review

This case study summarizes a completed astronomy chart-review assignment. Six figures were checked for chart type, data series, axes, legends, color, spacing, readability, and possible improvements.

## What the review demonstrates

- Plain-language evaluation of technical charts
- Identification of overplotting, contrast, labeling, and hierarchy problems
- Clear expected-versus-actual reasoning
- Specific redesign recommendations rather than vague criticism

## Files

- [`review-matrix.csv`](review-matrix.csv): issue and recommendation for each figure
- [`review-checklist.md`](review-checklist.md): reusable review process
- [`findings-summary.md`](findings-summary.md): concise case-study summary

The public portfolio uses an original summary graphic rather than republishing figures from outside scientific papers.
